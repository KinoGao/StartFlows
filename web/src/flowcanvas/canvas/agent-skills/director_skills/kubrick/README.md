# 导演风格 · 库布里克（对称冷峻）

## 简介

本技能包提供 **库布里克式对称构图与冷峻秩序感** 的导演风格参考，适用于心理惊悚、科幻、战争题材，强调形式感与疏离感。

## 核心美学

- **绝对对称** — 单点透视构图，视线被强制引向画面中心
- **冷峻理性** — 情感被形式压制，人物在宏大空间中显得渺小孤独
- **秩序下的不安** — 表面整洁对称，暗藏失控与疯狂

## 镜头语言

- **标志性推镜（库布里克推）** — 从远景沿中轴缓慢推近，压迫感逐渐增强
- **广角变形** — 走廊、房间用广角强化纵深透视，天花板压顶
- **上帝视角** — 俯拍对称场景，人物如棋盘上的棋子
- **过肩对峙** — 双人对峙用对称过肩镜头，力量对等

## 光线与色彩

- **单光源硬光**，明暗对比强烈，一半脸亮一半脸陷于阴影
- **荧光灯冷白** 与 **钨丝暖黄** 的冲突色温
- **高饱和色块点缀** 在低饱和环境中（如红色走廊、白色手术室）

## 运镜与构图

- **中轴对称** 是铁律，机位永远在轴线正中
- **缓慢移动**，拒绝手持，拒绝随意构图
- **几何图案**（瓷砖、走廊、门框）作为画面骨架反复出现

## 提示词约束

- 提示词中优先使用：`one-point perspective`、`perfect symmetry`、`slow axial push-in`、`wide-angle corridor`、`harsh single-source lighting`
- 避免：手持纪实感、自然主义光线、杂乱构图、明亮欢快氛围
- 人物表情倾向**克制、面无表情**，情绪通过环境传达
