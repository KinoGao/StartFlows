# 导演风格 · 诺兰（冷峻实拍科幻）

## 简介

本技能包提供 **诺兰式冷峻实拍与宏大叙事** 的导演风格参考，适用于科幻、悬疑、动作题材，强调真实质感、复杂结构与时间主题。

## 核心美学

- **实拍真实感** — 拒绝廉价 CG 感，场景、爆炸、城市都像真实存在
- **冷静克制** — 情绪被逻辑与任务压制，角色为信念行动
- **宏大与精密** — 时间、空间、记忆构成多层结构，画面与叙事同样精密

## 镜头语言

- **IMAX 大画幅** — 广阔地平线与城市全景，人物在环境中显得渺小
- **交叉剪辑** — 多时空并行推进，节奏由剪辑而非镜头运动制造
- **正反打对话** — 干净的过肩正反打，对话驱动冲突
- **实景大场面** — 车队、爆炸、机群用实拍规模感呈现

## 光线与色彩

- **冷蓝灰调** 为主，阴天质感，硬朗的环境光
- **低饱和低对比**，偶尔高光爆亮（爆炸、手电、屏幕）
- **金属与混凝土质感**，城市空间干净利落

## 运镜与构图

- **稳定克制**，大量固定机位与缓慢摇移，拒绝花哨运动
- **航拍大远景** 建立空间规模，然后切近景人物
- **对称与透视** 结合，走廊、大楼、驾驶舱形成强纵深感

## 提示词约束

- 提示词中优先使用：`imax wide establishing shot`、`cold desaturated palette`、`practical location realism`、`low-angle urban scale`、`hard directional light`
- 避免：霓虹赛博朋克高饱和、手持纪录片感、柔光梦幻氛围、夸张特效感
- 场景描述强调**真实尺度与物理质感**，人物姿态坚定克制
