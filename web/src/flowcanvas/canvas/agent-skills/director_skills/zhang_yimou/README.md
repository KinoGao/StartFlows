# 导演风格 · 张艺谋（东方色彩仪式）

## 简介

本技能包提供 **张艺谋式东方色彩美学与仪式感** 的导演风格参考，适用于古装、历史、东方题材，强调色彩冲击、对称构图与民族元素。

## 核心美学

- **色彩即叙事** — 大色块直接表达情绪与主题，红、金、青、墨色为主
- **仪式感** — 群体阵列、整齐动作、对称场面构成视觉奇观
- **东方写意** — 借景抒情，山水、灯笼、长街既是场景也是情绪

## 镜头语言

- **大全景群体场面** — 千人阵列、整齐划一的队伍与舞蹈
- **色彩主体特写** — 人物服饰、道具、环境中的主色反复强调
- **长镜头场面调度** — 复杂群体动作一镜完成，气势连贯
- **慢动作仪式** — 关键仪式动作放慢，增强庄严与张力

## 光线与色彩

- **高饱和浓郁色彩**，红墙金瓦、青绿山水、墨色剪影
- **强对比光**，阴影浓重，轮廓分明
- **色块分层** — 前景、中景、背景用不同色块建立纵深

## 运镜与构图

- **对称构图** 是基础，宫殿、广场、队列都居中取景
- **升降机运镜** 从低到高揭示群体场面全貌
- **横移长镜头** 扫过阵列与长街，展现规模

## 提示词约束

- 提示词中优先使用：`saturated red and gold`、`symmetric ceremony composition`、`mass formation wide shot`、`ink-wash silhouette`、`ornate chinese palace`
- 避免：低饱和灰调、西方自然主义、随意的手持构图
- 画面描述强调**色彩、阵列、仪式动作**，人物姿态整齐有力
