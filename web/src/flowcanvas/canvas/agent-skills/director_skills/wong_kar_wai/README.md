# 导演风格 · 王家卫（东方文艺迷离）

## 简介

本技能包提供 **王家卫式东方文艺与迷离情绪** 的导演风格参考，适用于都市爱情、文艺剧情、怀旧题材，强调氛围感与情绪碎片化表达。

## 核心美学

- **都市孤独** — 人物在霓虹都市中擦肩而过，疏离与渴望并存
- **时间碎片** — 用瞬间与留白拼贴情绪，不追求完整叙事因果
- **暧昧含蓄** — 情感不直说，靠眼神、雨、烟、狭窄走廊传递

## 镜头语言

- **手持跟拍** — 轻微晃动的人物跟拍，呼吸感与不安感并存
- **慢门拖影** — 霓虹灯拖出光轨，人物运动留下残影（招牌技法）
- **过肩与镜像** — 通过镜子、玻璃、水面拍摄，人物重叠互映
- **雨夜质感** — 雨滴、湿漉漉的街道、霓虹倒影反复出现

## 光线与色彩

- **霓虹青绿 + 暖橙红** 的撞色体系，高饱和但压低亮度
- **大面积阴影**，人物常半张脸隐没在暗处
- **颗粒感** 与轻微偏色，模拟胶片时代记忆质感

## 运镜与构图

- **慢速横移** 扫过街景与人物，时间感缓慢
- **局促构图** — 门框、窗帘、栏杆前景遮挡，制造窥视与压抑
- **跳切** 打破时空连续性，用重复动作组接情绪

## 提示词约束

- 提示词中优先使用：`neon-lit rainy street`、`slow shutter motion blur`、`teal and orange`、`film grain`、`smoky atmosphere`、`reflection in mirror`
- 避免：明亮日光、干净利落的商业片打光、全画面清晰锐利
- 画面描述要突出**情绪氛围**而非动作结果，人物表情含蓄克制
