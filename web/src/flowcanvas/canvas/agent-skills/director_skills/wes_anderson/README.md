# 导演风格 · 韦斯·安德森（对称童话）

## 简介

本技能包提供 **韦斯·安德森式对称构图与童话质感** 的导演风格参考，适用于喜剧、冒险、动画风格题材，强调形式美感、明快色彩与可爱秩序。

## 核心美学

- **完美对称** — 画面左右镜像对称，构图如插画般精致
- **明快童话** — 色彩糖果般鲜亮，世界干净可爱，冲突也带幽默感
- **平面化叙事** — 镜头如书页翻动，横移与推拉像舞台布景切换

## 镜头语言

- **正面直拍** — 人物正对镜头，居中构图，如证件照般直接
- **横移平移镜头** — 沿水平轴平移展示场景，像展开画卷
- **快速变焦推拉** — 突显道具与表情的戏剧性瞬间
- **俯拍桌面/地图** — 从正上方拍摄平面物体，平面构成感强

## 光线与色彩

- **均匀明亮光**，极少阴影，色彩饱和但柔和
- **马卡龙色系** — 粉、薄荷绿、奶油黄、淡紫的和谐组合
- **色块环境** — 墙面、地毯、服装用整块纯色区分空间

## 运镜与构图

- **正轴对称** 是铁律，一切元素围绕中轴布置
- **慢速横移** 与 **垂直升降**，运动平稳如机械
- **平面化空间** — 纵深浅，如舞台布景，前景后景分层清晰

## 提示词约束

- 提示词中优先使用：`perfect symmetrical composition`、`pastel color palette`、`flat stage-like depth`、`centered frontal framing`、`smooth lateral tracking`
- 避免：手持晃动、复杂自然光、暗黑氛围、现实主义的杂乱构图
- 画面描述强调**秩序与可爱**，人物表情略带呆萌的严肃感
