# 导演风格 · 维伦纽瓦（宏大静谧）

## 简介

本技能包提供 **维伦纽瓦式宏大静谧与压迫感** 的导演风格参考，适用于科幻、史诗、惊悚题材，强调空间的巨大尺度、声音的沉默与克制的紧张。

## 核心美学

- **宏大尺度** — 巨物、巨构、空旷荒野，人物如尘埃般渺小
- **静谧压迫** — 少对白多沉默，紧张感来自环境与等待
- **极简克制** — 叙事留白，视觉干净，情绪不外放

## 镜头语言

- **超远景建立** — 用巨大的环境镜头先压住观众，再切入人物
- **慢速推进** — 缓慢接近主体的推镜，紧张感逐步累积
- **对称与纵深** — 建筑、飞船、沙丘形成强烈的几何纵深
- **低机位仰拍** — 巨物压顶的压迫感

## 光线与色彩

- **低饱和灰褐、沙色、冷蓝** 为主的自然主义色调
- **硬朗的侧光与阴影**，轮廓分明
- **雾霾与尘埃** 增加空间层次与神秘感

## 运镜与构图

- **极慢的运动**，拒绝快切与炫技
- **人物居中或置于画面极小位置**，强调渺小
- **长镜头延续**，场景切换克制，节奏如呼吸

## 提示词约束

- 提示词中优先使用：`vast epic wide shot`、`tiny figure in huge landscape`、`slow dolly push-in`、`desaturated earthy palette`、`haze and dust atmosphere`
- 避免：快节奏蒙太奇、高饱和彩色、明亮欢快氛围、手持纪实感
- 画面描述突出**尺度对比与静谧氛围**，人物动作缓慢克制
