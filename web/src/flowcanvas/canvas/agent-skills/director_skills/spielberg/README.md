# 导演风格 · 斯皮尔伯格（好莱坞主流叙事）

## 简介

本技能包提供 **斯皮尔伯格式好莱坞主流叙事** 的导演风格参考，适用于需要强情感共鸣、清晰叙事与奇观场面兼顾的影视创作。任何题材均可叠加使用。

## 核心美学

- **奇观与情感并重** — 大场面服务于角色情感，每个奇观镜头都落在具体人物的反应上
- **孩子般的好奇视角** — 镜头保持对世界的惊叹感，用仰视与低机位放大渺小与宏大
- **经典好莱坞叙事** — 三幕结构清晰、目标明确、情感弧线完整，观众始终知道该感受什么

## 镜头语言

- **逆光剪影** — 主体背对光源形成金边轮廓，是标志性视觉签名（黄昏、门框、窗光）
- **面部特写反应镜头** — 关键情节切到角色面部反应，用眼睛传递情绪
- **标志性长镜头** — 复杂场面用一镜到底跟拍建立空间真实感
- **主观视角镜头** — 让观众透过角色眼睛看世界，增强代入

## 光线与色彩

- **暖金逆光** 为主基调，黄昏与黎明时段是黄金拍摄窗口
- **高光过曝但不刺眼**，暗部保持胶片颗粒感
- **色彩温暖饱和**，肤色通透，天空蔚蓝带金色边缘

## 运镜与构图

- **缓慢推近** 强化情绪浓度，**快速甩镜** 衔接动作爆发
- **低机位仰拍** 人物与建筑，**环绕运镜** 揭示场景全貌
- **三分法构图** 为基准，重要主体置于交点，地平线干净

## 提示词约束

- 提示词中优先使用：`golden backlight`、`warm cinematic glow`、`heroic low angle`、`reaction close-up`、`one-take tracking shot`
- 避免：冷蓝恐怖氛围、高对比硬光、手持剧烈晃动、实验性构图
- 画面描述要包含**人物的情绪反应**，不能只写场面本身
