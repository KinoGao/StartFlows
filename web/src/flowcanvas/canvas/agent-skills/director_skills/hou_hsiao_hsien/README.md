# 导演风格 · 侯孝贤（长镜头写实）

## 简介

本技能包提供 **侯孝贤式长镜头与东方写实主义** 的导演风格参考，适用于文艺、乡土、历史题材，强调时间的流逝、生活的日常与克制的情感。

## 核心美学

- **时间感** — 镜头不打断生活，让事件在真实时间里自然发生
- **旁观视角** — 摄影机如旁观者，不干预、不引导视线
- **留白与沉默** — 大量空镜、停顿与日常琐碎，情绪在沉默中累积

## 镜头语言

- **固定长镜头** — 一场戏一个镜头，拒绝分切，机位几乎不动
- **深焦全景** — 人物在环境中完整呈现，不做主观引导
- **空镜转场** — 用山水、田野、走廊的空镜完成时间跳跃
- **远景叙事** — 关键情绪常放在远景，人物背影传达一切

## 光线与色彩

- **自然光** 为主，晨昏、阴天、室内窗光的柔和层次
- **低饱和大地色**，青灰、土黄、墨绿构成东方乡土色调
- **胶片颗粒**，画面呼吸感强，不过度修饰

## 运镜与构图

- **固定机位** 占绝对主导，偶有极缓慢的横移
- **门框、窗框、树木作前景**，形成自然的画框层次
- **地平线稳定**，构图安静朴素，拒绝炫技

## 提示词约束

- 提示词中优先使用：`static long take`、`deep focus wide shot`、`natural window light`、`earthy desaturated palette`、`framing through doorway`
- 避免：快切蒙太奇、手持晃动、高饱和撞色、戏剧化打光
- 画面描述突出**日常细节与安静氛围**，人物动作自然不表演
